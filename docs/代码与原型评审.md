# 汐眠代码与原型评审

> 版本：v0.1.1-mvp｜日期：2026-09-19

## 评审发现（已修复）

| 问题 | 严重性 | 处理 |
|------|--------|------|
| Records 仅内存时间线，重启丢失 | 高 | DataStore 持久化 `NightSummary` 列表 |
| 默认 15min 延迟阻碍演示 | 高 | 新增「演示」预设：30s 延迟 / 10min 上限 |
| `PinkNoisePulsePlayer` 每脉冲 stop/flush | 中 | 复用 STREAM AudioTrack，仅 write |
| 首页 UI 与原型差距大 | 中 | 大圆钮 CTA、设备状态芯片、靛蓝主题 |
| 无首次免责声明 | 中 | Onboarding 弹窗 + 必选勾选 |
| SessionEngine 延迟阶段出睡未明确取消 | 中 | `WaitingDelay` 阶段 + 取消 delayJob |
| 新夜晚未归档旧会话 | 中 | `archiveSessionIfNeeded` + 幂等 stop |
| 小米路径指引分散 | 低 | Devices 页内嵌 SDK/米家 checklist |

## 锁定产品决策（本版实现）

1. **安全预设**
   - `演示`（首次安装默认）：延迟 30s、最长 10min、音量 20%
   - `科学默认`：延迟 15min、最长 90min、音量 25%
   - 设置页可切换预设并微调 → 自动标记为 `自定义`

2. **持久化（DataStore）**
   - `SafetyConfig`、`SleepMonitorSource`、`disclaimerAccepted`
   - 已完成夜晚摘要：`date`、timeline、`pulseCount`、`stopReason`

3. **Onboarding**
   - 首次启动模态：非医疗免责 + 必选勾选
   - 「试听一发脉冲」：设置页与 Onboarding 均可触发

4. **UI 对齐原型**
   - Tonight：大圆钮「开启今晚」、演示预设标签、手表/音箱/手机芯片
   - SessionActive：时间线 + 醒目停止按钮
   - 深海军蓝 + 靛蓝主题；用户可见文案全中文

5. **音频**
   - 50ms 1/f 粉红噪声 + 淡入淡出包络 + 音量上限
   - 稳定 STREAM 路径，释放时才 stop/flush

6. **SessionEngine**
   - 状态：`Idle → Arming → WaitingSleep → WaitingDelay → Stimulating → Stopped`
   - 新夜晚开始前归档；延迟中出睡即停；stop 幂等
   - JVM 单元测试覆盖主要状态迁移

7. **小米路径**
   - 默认 Fake；XiaomiWear Stub + Devices checklist + 科学页向导

8. **版本**
   - `0.1.1-mvp`

## 演示流程（≤1 分钟）

1. 首次启动 → 勾选免责 → 「开始使用」
2. 确认预设为「演示」（Tonight 页可见标签）
3. 「开启今晚」→ 设备页「模拟入睡」
4. 等待 30s → 进入稀疏脉冲（SessionActive 时间线更新）
5. 「模拟醒来」或「立即停止」→ 记录页可见持久化历史
