# 小米穿戴与米家接入指南

汐眠 v0.2.0 提供两条睡眠检测通路，包名 **`com.tidesleep.app`**。

> 无 EEG 时为开放环（入睡触发），不等于医疗诊断或治疗。睡眠状态来自穿戴算法，可能存在数分钟延迟。

---

## Path A — 米家自动化深链（无需 AAR，今日可用）

### 前置条件

| 项目 | 要求 |
|------|------|
| 穿戴 | 手环/手表已绑定「小米运动健康」 |
| 米家 | App ≥ 10.0，已开启运动健康数据访问 |
| 设备列表 | 穿戴出现在米家「我的设备」 |
| 上报通道 | HyperOS 2+ 小米手机，或蓝牙 Mesh 网关 |

部分小爱音箱型号**不能**作为 Mesh 网关，请以米家实际提示为准。

### App 内设置

1. **设备** Tab → 选择 **米家自动化**
2. **今晚** → **开启今晚**（启动前台服务，保持会话监听）

### 米家自动化配置

创建两条自动化（或一条带多条件）：

| 触发 | 动作 |
|------|------|
| 穿戴「睡眠状态」= **睡着** | **打开链接** `tidesleep://sleep?state=asleep` |
| 穿戴「睡眠状态」= **醒来** | **打开链接** `tidesleep://sleep?state=awake` |

备选：发送广播

- Action：`com.tidesleep.app.ACTION_SLEEP_STATE`
- Extra：`state` = `asleep` 或 `awake`

### 截图 checklist（建议留存）

- [ ] 米家「人车家数据访问」运动健康开关
- [ ] 穿戴设备出现在米家列表
- [ ] 自动化「若 睡眠状态 = 睡着」条件页
- [ ] 「打开链接」动作填写深链
- [ ] 汐眠设备页显示「米家桥接」且睡眠状态更新

## Path B — 小米穿戴第三方 SDK（需官方 AAR）

### 申请流程

1. 登录 [HyperOS 开放平台](https://dev.mi.com/)
2. 创建应用，**包名** `com.tidesleep.app`
3. 申请「小米穿戴第三方 App 能力开放」
4. 填写应用签名 SHA1/SHA256（调试：`./gradlew :app:signingReport`）
5. 审核通过后下载 **wearable AAR**（接口文档 v1.4）

### 放入工程

```text
android/app/libs/
  └── wearable-xxx.aar    # 官方文件名以平台为准
```

可选：在 `android/gradle.properties` 设置 `tidesleep.xiaomiSdk=true`（`libs/` 有 AAR 时会自动启用）。

详见 `android/app/libs/README.md`。

### 运行时 API（与官方文档一致）

```text
Wearable.getNodeApi(context) / getAuthApi(context)
  → getConnectedNodes()
  → requestPermission(nodeId, DEVICE_MANAGER, NOTIFY)
  → query / subscribe(nodeId, DataItem.ITEM_SLEEP, …)
```

睡眠状态：睡眠中/清醒；事件：入睡/出睡。

### 无 AAR 时

工程仍可编译；设备页选择「小米穿戴 SDK」会提示 **未找到小米穿戴 SDK AAR**，请改用 Path A。

---

## 会话行为（两条路径相同）

`SessionEngine` 契约不变：

- **入睡** → 等待「入睡延迟」→ 开始稀疏粉红噪声脉冲
- **醒来** → 立即停止
- 出睡即停、单晚上限、非医疗免责
